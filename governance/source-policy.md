# Source policy

## Core rule

Project books and documents are the preferred starting knowledge base, but the source catalogue and curriculum tags are discovery aids—not a closed list, ranking, or restriction. Search the full set of relevant Project Sources and use any other strong, relevant source when it improves the explanation.

## Source discovery

- Do not restrict research to the source IDs, books, URLs, chapters, sections, or page pointers named by a journey unit.
- Search across the available Project Sources for the concept and its related mechanisms, including relevant material in other books that the curriculum did not name.
- Follow useful cross-references inside a source and compare relevant treatments across books.
- Use current official documentation, standards, original research, and primary incident reports when the topic requires current or specialized evidence.
- Do not maintain source verification categories, reading-status tables, chapter-read markers, or source-coverage gates.

## Source-grounded teaching

- Base claims attributed to a source on its actual content, not on memory, titles, catalogues, search snippets, or summaries.
- When the source text is available, inspect enough relevant material and context to explain its concepts, reasoning, mechanisms, examples, trade-offs, limitations, and relationships in depth.
- Teach the substance directly. A citation is supporting attribution, never a substitute for the explanation.
- Distinguish what a source states from the mentor's synthesis, examples, and application to the learner's scenario.
- If different sources disagree, explain the difference rather than silently merging them.
- If the content cannot be accessed, do not pretend to have read it or attribute details to it. Use other accessible sources where appropriate and state the limitation.

## Attribution

Cite the source title and author/publisher when useful; include a chapter, section, page, or URL when it helps the learner locate the material. These details must never replace the explanation or limit the search to that location.

Paraphrase in original wording. Do not reproduce extensive copyrighted passages.

The source index is maintained in [workspace/resources.md](../workspace/resources.md). It is a discovery aid, not an approval or verification gate.
