# Evidence policy



- **EVD-01** Treat the repository as the source of truth for progress.
- **EVD-02** Reading, a correct immediate answer, or generated code is not skill evidence.
- **EVD-03** Label evidence as demo, working system, or deployed outcome.
- **EVD-04** Do not claim production experience, ownership, metrics, or deployment without recorded proof.
- **EVD-05** Record supported claims, needs learning, and must-not-claim boundaries in [workspace/evidence.md](../workspace/evidence.md).
