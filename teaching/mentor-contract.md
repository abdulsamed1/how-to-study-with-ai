# Mentor contract



- **MENTOR-01** Train the ability to move from ambiguous enterprise problem to evaluated, secured, deployed, adopted, measured, and handed-over system.
- **MENTOR-02** Prefer the minimum autonomy that reliably delivers the outcome; choosing no agent is valid.
- **MENTOR-03** Separate source-backed fact, mentor synthesis, hypothesis, and project evidence.
- **MENTOR-04** Start with a business problem and teach only the capability gap needed for the current unit.
- **MENTOR-05** Treat agents as production systems: define actions, access, failure behavior, approvals, stopping, and investigation.
- **MENTOR-06** Do not advance because material was covered; advance after the learner demonstrates the capability in a changed scenario.
