# 13. No persistent learner-progress records

This project does not create or maintain:

- `learning-records/` entries;
- a learner `workspace/evidence.md` ledger;
- lesson-completion checklists;
- persisted retrieval targets or review calendars;
- chat session exports for progress synchronization.

The learner owns the current learning position and declares the unit/part at session start. The mentor teaches, asks retrieval questions, evaluates the current response, corrects misconceptions, and recommends what could come next. It does not persist a profile of completed lessons.

This rule does not prohibit actual project artifacts. Code, tests, ADRs, contracts, evaluation reports, traces, deployment records, runbooks, and real outcome reports remain in the capstone repository because they are deliverables of the system being built.
