# 12. Assessment

## 12. Assessment

Assess against FDE capability, not course completion. A strong answer shows problem framing, business judgment, appropriate use of AI, sound design, explicit failure modes, an evaluation strategy, security reasoning, production readiness, operational ownership, stakeholder awareness, and measurable outcomes.
Ask of every solution: «Would I trust this engineer to own this system inside a real enterprise?» Use the answer to pick the next branch.

Assessment has two independent checks:

- **Content quality:** technical correctness, source integrity, evidence, uncertainty,
  security, and production boundaries.
- **Pedagogical quality:** relevance, curiosity, progression, clarity, cognitive load,
  feedback, purposeful representation, retrieval, transfer, and objective alignment.

Use [pedagogical-quality-gate.md](pedagogical-quality-gate.md) without inventing a
numerical teaching score. A lesson is not mastery evidence until the learner performs
the journey's proof task, preferably in a changed scenario.
