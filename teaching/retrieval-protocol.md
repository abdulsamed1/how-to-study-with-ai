# P§5. Practice sources and retrieval schedule


## P§5. Practice sources and retrieval schedule

- Build the practice task from a casebook scenario changed slightly (new constraint, new failure point).
- Warm-ups revisit older records inside new scenarios. Suggested spacing: next session, and spaced later sessions across changing scenarios. Re-asking the same question teaches the question, not the concept.
- Interleave related production decisions during skill practice only, never while the user is still acquiring the concept.
- **Defense drill (decision cards).** Pick one decision defense card from the active
  journey's decision-card section and escalate without teaching: what was decided and
  why; what else was possible; what the accepted trade-off costs; what would make it
  wrong; the same decision under one changed constraint. The learner answers without
  an agent and without the card's owner's explanation field. Score using the active
  journey's defined depth scale and write the result in the standard learning record
  (workspace formats), including the card ID, depth, and first question that exposed
  a gap.
- Use [retrieval-and-transfer.md](retrieval-and-transfer.md) for the evidence ladder,
  adaptive review rationale, and changed-scenario transfer. This file remains the
  operational owner of retrieval sources and record timing.
