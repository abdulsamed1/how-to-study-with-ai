# Adaptive lesson blueprint

This is an internal planning artifact. Do not show the checklist to the learner.
Use it to design a coherent conversation, then revise it from the learner's response.
Not every field needs a distinct teaching move.

| Design dimension | Planning question |
|---|---|
| Outcome | What observable capability will the learner demonstrate? |
| Existing knowledge | What evidence, records, and diagnostic response show what is already known? |
| Prerequisites | Which hard prerequisite must be verified, and which adjacent concept can remain a bridge? |
| Gaps | What is the smallest missing relationship needed for this outcome? |
| Misconceptions | Which tempting model or incorrect approach should be tested? |
| Curiosity hook | What concise question, contradiction, or consequence creates a reason to care? |
| Scenario | What facts, constraints, unknowns, and decision make the problem concrete? |
| Prediction | What useful outcome, comparison, or failure can the learner predict? |
| Discovery | In what order will observations make the concept necessary? |
| Examples | Which concrete example and changed example expose the mechanism? |
| Visual | Which one visual type communicates the causal or structural relationship? |
| Analogy | What does the analogy illuminate, and where does it stop being accurate? |
| Disclosure | What should be intuitive, concrete, conceptual, mechanistic, and precise? |
| Boundaries | Which failure, exception, trade-off, or non-goal changes the decision? |
| Retrieval | What can the learner recall without seeing the explanation? |
| Transfer | What unfamiliar scenario tests the underlying idea? |
| Mastery | What independent performance meets the journey's proof criteria? |
| Retention | Which existing record or later unit should revisit this idea, and why? |

## Design sequence

1. Select the journey unit, source boundary, and one outcome.
2. Fill only the fields needed to choose the next instructional move.
3. Begin with the problem and ask one focused framing or prediction question.
4. Update gaps, misconceptions, and support level from the response.
5. Deliver through the four parts in [P§3](lesson-protocol.md).
6. Record demonstrated evidence and a future retrieval opportunity; do not record
   coverage as mastery.

## Route selection

Choose techniques using concept difficulty, learner knowledge, objective, cognitive
load, subject matter, and interaction history. Use direct explanation when requested,
when the learner has already reasoned sufficiently, or when further discovery would
add friction without learning value.
