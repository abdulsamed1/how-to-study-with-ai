# Optional book starting points

The following books are useful starting points, not an exclusive list or prescribed chapter sequence. Search all available Project Sources for the topic and use other books or primary sources whenever they provide better depth or a stronger explanation.

- [Foundations of Scalable Systems — Ian Gorton](https://www.oreilly.com/library/view/foundations-of-scalable/9781098106058/) (S28)
- [Understanding Distributed Systems — Roberto Vitillo](https://understandingdistributed.systems/) (S27)
- [Designing Distributed Systems — Brendan Burns](https://www.oreilly.com/library/view/designing-distributed-systems/9781098156343/) (S29)
- [Designing Data-Intensive Applications — Martin Kleppmann and Chris Riccomini](https://www.oreilly.com/library/view/designing-data-intensive-applications/9781098119058/) (S19)
- [Fundamentals of Software Architecture — Mark Richards and Neal Ford](https://www.oreilly.com/library/view/fundamentals-of-software/9781098175504/) (S20)
- [Software Architecture: The Hard Parts — Neal Ford, Mark Richards, Pramod Sadalage, and Zhamak Dehghani](https://www.oreilly.com/library/view/software-architecture-the/9781492086888/) (S38)

Also search the Project Sources for user-supplied performance books, handbooks, articles, incident reports, and other material. Do not restrict explanations to this list or to chapter pointers embedded in individual units.

Use real incident reports and primary engineering documentation when a topic concerns specific system behavior. Explain source-derived mechanisms in depth, then distinguish their application to the learner's scenario from what the source itself states.
