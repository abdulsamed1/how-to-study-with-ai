# How to use the source index

The source index contains only stable IDs, source names, and URLs. It helps locate material; it does not decide which material the mentor may use.

- Treat every listed source as a starting point, not an exclusive or preferred answer.
- Search all available Project Sources for the topic, including books and documents not named in the active journey.
- Do not require a source to be pre-verified, assigned a status, or recorded as previously read before it can be considered.
- Do not track which chapters or pages the AI has read. Do not use TOC, read, or similar reading-state markers.
- Do not limit a lesson to chapters listed in a curriculum unit. Search broadly across the relevant book and related books, following useful cross-references.
- When source content is accessible, inspect the relevant material and teach its substance. Do not replace the explanation with a chapter pointer.
- When source content is not accessible, do not invent or attribute details to it. Use other accessible sources or state the limitation.
- Add sources by preserving a stable ID where one already exists and recording the source name and URL. No additional status, format, coverage, or reading metadata is required.

The learner's Project Sources remain the larger library. This index is not a complete inventory of everything uploaded to the Project.
